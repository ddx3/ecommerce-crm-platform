{% comment %} Shared tab controller for Quill editors. Combines several editors (Description / Raw text / Norms / ...) into ONE block with a tab switcher, collapsing (click on the panel outside the tabs) and a data-presence indicator. API: window.PGQuillTabs(items, mount, opts) items: [{el, label, open, filled}] el — editor container (form-row, .quill-wrapper or a wrapper) open — fn to expand the Quill of the active tab filled — (opt.) fn -> bool: whether there is data (when the textarea/.ql-editor is not inside el) right — (opt.) push the tab (or its group) to the right edge of the panel mount — mount node; opts.before=true → insert BEFORE mount block.__refreshDots() — recompute the data-presence indicators. The block updates them itself when the DOM inside changes (typing in Quill, programmatic filling, lists); a manual call is needed when data changes without a DOM change - the value of a plain textarea or state outside el (when filled is given) window.pgRevealEditor(node) — expand the block and activate the tab of node {% endcomment %} {% load static %} {% comment %} Quill is loaded only here (pages with an editor), not globally in base_site.html — otherwise 209KB of JS + CSS blocked the rendering of EVERY admin page, including lists. {% endcomment %}
